LiliumDB

C++

Details GitHub ↗

LiliumDB is a relational storage engine built as a learning project to explore data storage and systems engineering.

  • Features:

    • Paged single-file format
    • LRU buffer pool
    • B+ tree clustered index
    • Variable-length records

  • Roadmap:

    • Relational database tables
    • Full SQL implementation
    • Query optimizer

  • Status:

    In active development.

Dungeons & Dragons Character Sheet

Java, JavaFX, SceneBuilder

Details GitHub ↗

This D&D character sheet application was built as a group project for a Software Engineering course. It stores a character’s level, stats, and skills digitally and automates skill checks. I built the entire GUI myself and hooked it into the backend developed by the rest of my group.

  • Features:

    • GUI built in SceneBuilder
    • Roll checks for:
      • Ability checks
      • Skill checks
      • Saving throws

  • Roadmap:

    • Database for storage
    • Full race and class implementations
    • Character builder
    • Character leveler

  • Status:

    Not in active development.

PGNtoCSV

Python

Details GitHub ↗

This is a simple Python script to process a PGN file storing millions of professional chess matches to produce a CSV file cataloguing openings, player ratings, and game outcomes for statistical analysis.

  • Features:

    • Loads and parses PGN files
    • Outputs CSV file with data to analyze

  • Roadmap:

    • Expanded data parsing
    • User interface

  • Status:

    Not in active development.
