LiliumDB

C++

Details GitHub ↗

LiliumDB is a relational storage engine built as a learning project to explore data storage and systems engineering.

Features:

  • Paged single-file format
  • LRU buffer pool
  • B+ tree clustered index
  • Variable-length records

Roadmap:

  • Relational database tables
  • Full SQL implementation
  • Query optimizer

Status:

In active development.

PGNtoCSV

Python

Details GitHub ↗

This is a simple Python script to process a Portable Game Notation (PGN) file storing millions of professional chess matches to produce a CSV file cataloguing openings, player ratings, and game outcomes for statistical analysis.

Features:

  • Loads and parses PGN files
  • Outputs CSV file with data to analyze

Roadmap:

  • Expanded data parsing
  • User interface

Status:

Not in active development.
